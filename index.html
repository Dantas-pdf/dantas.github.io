FramerVault — Project Details

FramerVault is a full-stack game library and journal built to help players organize their games, track playtime and ratings, sync their Steam library, explore recommendations and sales, and share libraries with friends.

Technologies and integrations

  • TypeScript: application and API code.
  • React 19 and Next.js 16: interactive UI and App Router.
  • Supabase: authentication and PostgreSQL database, with custom SQL functions and row-level security.
  • CSS: custom styling and responsive layouts.
  • Recharts: playtime and activity charts.
  • Steam APIs and OpenID: account linking, library import and sync, and deal data.
  • RAWG API: game catalog.

UnderVeil — Project Details

UnderVeil is a solo-developed action roguelike built in GameMaker Studio 2 using GML. Its architecture is modular and backward-compatible, so new systems can be added without changing existing behavior.

Dungeon generation

  • Directional room choice blends ideas from The Binding of Isaac and Hades; players select an exit and its reward room by room.
  • Rooms are carved procedurally around a fixed anchor point. Previous rooms are destroyed during transitions to limit active instances and memory use.
  • Notch carving creates L-shape, zigzag, pinwheel, and cross combat layouts while preserving gate and center logic.
  • Each dungeon has a ten-room combat floor. Midway through, an excursion routes players to hand-built elite arenas; a generalized trigger object handles activation for elites and bosses.

Combat systems

  • Movesets: a data-driven dispatcher gives each weapon its own attack chain on top of a shared framework.
  • Status effects: Burn, Poison, Frost, Bleed, Fear, and Curse each have rules for duration, stacking, refreshing, and thresholds. Weapons can have a default status; Bleed and Curse thresholds vary by enemy.
  • Enemy hierarchy: base, elite, and boss enemies share layered behavior, including summoner-linked deaths, death-state guards, and EXP handling designed to prevent exploits.

Progression

  • The Omen upgrade system uses weighted reward pools to shape each run.
  • The Fates Room allows eligible Omens to be exchanged for escalating HP and gold costs.
  • A persistent skill tree and loadout menu support progression between runs.

Rendering and game feel

  • Timing: movement and timers run on delta time.
  • Lighting: a custom ambient-darkness system with light cutouts replaced a third-party lighting library to recover performance.
  • Shaders: custom effects handle desaturation and rarity-based weapon glow and shine.
  • Effects and UI: particle effects, nine-slice rendering, staggered card reveals, and fade-driven room transitions with per-area music.

Technology

  • Engine: GameMaker Studio 2 with GML.
  • Input: the verb-based Input library supports keyboard and controller play, including left-stick aiming.
  • Saves: three-slot auto-save system, with settings stored separately.
