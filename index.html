FramerVault — Project Details

FramerVault is a full-stack game library and journal built to help players organize their games, track playtime and ratings, sync their Steam library, explore recommendations and sales, and share libraries with friends.

Technologies and integrations

  • TypeScript: application and API code.
  • React 19 and Next.js 16: interactive UI and App Router.
  • Supabase: authentication and PostgreSQL database, with custom SQL functions and row-level security.
  • CSS: custom styling and responsive layouts.
  • Recharts: playtime and activity charts.
  • Steam APIs and OpenID: account linking, library import and sync, and deal data.
  • RAWG API: game catalog.
